# Internship Management System

A full-stack Internship Management System developed using Flutter and ASP.NET Core Web API to streamline the internship application and management process.

## Features

- User Registration and Login
- JWT Authentication and Authorization
- Student Dashboard
- Internship Role Management
- Internship Application Submission
- Application Status Tracking
- Mentor Management
- Internship Assignment Management
- Admin Dashboard
- SQL Server Database Integration

## Tech Stack

### Frontend
- Flutter
- Dart

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- JWT Authentication

### Database
- SQL Server

## Architecture

Flutter App → ASP.NET Core Web API → Entity Framework Core → SQL Server

## Project Objective

To provide a centralized platform where students can apply for internships, mentors can manage assigned students, and administrators can oversee the complete internship lifecycle efficiently.
